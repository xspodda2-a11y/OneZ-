# 永劫長風 · WINDS OF ETERNITY

An original, fully playable 3D open-world **wuxia action RPG** that runs in the browser.
No downloads, no plugins, no installed assets: **every mountain, village, face, melody and
sound effect in this game is generated by the code in this repository at runtime.**

> Inspired by the landscapes, martial-arts cinema and folklore of the jianghu tradition.
> It copies no existing game, and contains no extracted or third-party art, audio or models.

---

## Play

```bash
npm install
npm run dev          # http://localhost:5173
```

Production build:

```bash
npm run build        # → dist/
npm run preview
```

Requires a WebGL2-capable desktop browser. 60 FPS target; graphics presets LOW → ULTRA in
**Settings**, plus adaptive resolution that quietly protects the frame rate.

### Controls

| Input | Action |
| --- | --- |
| `W A S D` | Move |
| Mouse | Camera (click the canvas to capture the mouse) |
| Left click | Light attack (3-hit chain) |
| Right click | Heavy attack · hold to block |
| `Shift` + direction | Dodge roll |
| `Space` | Jump · hold to glide once *Lightness Skill* is learned |
| `F` | Parry (strike just before the blow lands) |
| `Q` / `R` | Whirlwind Lotus / Shadowless Step (qi) |
| `Tab` | Lock on · switch target |
| `E` | Interact: talk, open chests, gather herbs and ore |
| `H` | Drink a potion |
| `B` | Sheathe / draw |
| `I` `C` `J` `M` | Pack · Cultivation · Journal · Map |
| `Esc` | Pause |

## What is in the game

- **Open world** — 2.56 km² of fractal mountains, lakes, rivers, bamboo and pine forest,
  caves, farmland, mist and snow caps, streamed in chunks with LOD terrain and instanced
  vegetation.
- **Hand-built places** — 13 named points of interest generated by a procedural settlement
  builder: Willow Bend village, Cloudrest Town, Cloudsea Monastery, Nine Heavens Pagoda,
  Blackwood Camp, Bloody Cliff arena, the Hermit's Hut, Reedwharf docks, two caverns and
  more, joined by painted dirt roads.
- **Combat** — weighty third-person martial arts: light chains, heavy blows, blocking that
  drains stamina, i-frame dodge rolls, and a parry with a real timing window that breaks
  an enemy's guard and opens a counter-attack finisher. Poise, knockback, hitstop, screen
  shake, weapon trails, qi specials.
- **Enemy AI** — bandits, jianghu swordsmen, spearmen, Iron Guard elites and the boss
  **Hei Shan, the Black Mountain**, with patrol / alert / chase / strafe / windup / block /
  dodge / stagger / recover states, line-of-sight checks, attack tokens so you are never
  dogpiled, telegraphs, projectile fans and three boss phases.
- **RPG** — level and XP, 13-node martial-arts skill tree (gliding, double leap, qi
  circulation, sword mastery…), 20 items across weapons, armour, trinkets, consumables,
  materials and quest items, equipment stats, gold, shops, loot and chests.
- **People and quests** — 10 NPC archetypes with wander behaviour, greetings, lore, shops,
  training and rest; 8 quests (4 main story + 4 side) with talk / kill / collect / reach /
  boss / free objectives, gated by prerequisites and locations.
- **Systems** — day/night cycle with six weather states (clear, cloudy, rain, thunderstorm,
  snow, mist) and GPU precipitation, swimming, procedural music that shifts between
  explore / combat / boss / menu moods, three save slots in IndexedDB, minimap, full realm
  chart, toasts, tutorial hints and a Chinese ink-wash interface.

## Repository layout

```
src/
  game/
    core/        noise, input, events, terrain height field, capsule physics
    render/      renderer + post stack, sky, weather/environment, water
    world/       height map, mesh builder, structures, terrain streaming,
                 vegetation instancing, world generation (POIs, roads, spawns)
    character/   skeleton, body parts, rig, weapons, cloth ribbons, clips, animator, actor
    combat/      attack tables, hit resolution, hitstop
    player/      player controller: locomotion, climb, swim, glide, combat, camera rig
    ai/          enemy definitions and finite-state machine
    npc/         NPC definitions, behaviour, dialogue builder
    quests/      quest definitions and quest system
    rpg/         items, skills, progression
    audio/       procedural Web Audio engine (score + SFX)
    save/        IndexedDB save system
    VFX.ts       particles, slashes, trails, damage numbers, camera shake
    Game.ts      orchestrator: streaming, spawning, interaction, save/load, HUD feed
  ui/            React interface (menu, HUD, dialogue, panels, world map)
  state/store.ts Zustand store bridging game → UI
tools/           headless test harnesses (see below)
```

## Verification

There is no browser in this project's CI, so the game is verified by three headless
harnesses that actually execute the real code:

```bash
npm test            # typecheck + all three harnesses
npm run test:sim    # builds the world, spawns entities, simulates 10 s of scripted play
npm run test:ui     # renders every interface state through react-dom/server
npm run test:shaders# parses every custom GLSL stage
```

`tools/headless.ts` runs the genuine game loop (terrain streaming, vegetation, AI, combat,
quests, drops, save round-trip, death and respawn) against a stub renderer and reports
movement, damage, XP, loot and errors. It is how the systems above were validated.
